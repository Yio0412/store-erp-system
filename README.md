# 门店 ERP 管理系统

线下零售全流程管理平台，支持卫浴、厨具、五金配件、开关电线等多品类门店。

## 功能模块

- **工作台** — 数据看板、销售趋势、库存预警
- **收银台** — 扫码收银、改价、会员积分/储值、优惠券、二维码收款
- **订单管理** — 订单查询、退款、打印小票、Excel 导出
- **商品管理** — 商品 CRUD、图片头像、分类、商品模板库
- **库存管理** — 扫码入库/出库、批次保质期管理（FEFO）、库存查询
- **供应商管理** — 供应商档案、关联入库记录
- **调拨管理** — 多门店调拨、店长审批
- **会员营销** — 会员积分/储值、优惠券、折扣规则
- **数据统计** — 日/周/月/季/年报表、Excel 导出
- **系统设置** — 门店管理、角色权限、邀请码、打印机、小票模板

## 技术栈

- 纯前端实现（HTML + CSS + Vanilla JS）
- localStorage 数据持久化
- 支持 USB / 蓝牙扫码枪
- 58mm 热敏小票打印 + A4 打印
- 适配平板 / PC

## 快速开始

```bash
# 本地运行
python -m http.server 8081
# 访问 http://localhost:8081
```
